# Audio Assets untuk UNO Matematika

Letakkan semua file audio di folder:

```txt
assets/audio/
```

Nama file harus sama persis agar otomatis dipakai oleh kode.

## Musik

### 1. Musik Halaman Awal
```txt
assets/audio/menu-music.mp3
```
Prompt/arah musik:
```txt
Loopable cheerful kawaii mobile game menu music, upbeat, cute synth bells, soft marimba, happy arcade feeling, child friendly, bright and colorful, 90-110 BPM, seamless loop, no vocals
```

### 2. Musik Saat Bermain
```txt
assets/audio/game-music.mp3
```
Prompt/arah musik:
```txt
Loopable playful card battle puzzle game background music, energetic but not distracting, cute synth, light percussion, math learning game vibe, mobile casual game style, 100-120 BPM, seamless loop, no vocals
```
